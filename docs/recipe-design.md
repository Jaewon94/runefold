# 조합식 레시피표 설계 (초안, RUNE-67)

상태 표기: **확정** = 사용자가 정했다 / **잠정** = 시험·실측 뒤 확정 / **미정** = 아직 정하지 않음 / **가정** = 임시 적용

## 1. 조합식 원칙

### 1-1. 기본 규칙 (출처: design.md 「합성과 등급」)

| 항목 | 내용 | 상태 |
|---|---|---|
| 재료 수 | 서로 다른 유닛·카드 **2~3개** | 잠정(G3 비교) |
| 결과 | 새 이름의 하나. **항상 ★1(Lv1)로 시작** | 잠정 |
| 레시피표 | **고정 레시피표**로 관리. 같은 재료는 항상 같은 결과 | 잠정 |
| 대상 | 유닛·카드. **유물 제외** | 확정(2026-10-21) |
| 합성 시점 | 야영지·상점 전후의 정리 화면. 플레이어가 직접 확정(자동 아님) | 잠정 |
| 재료 소모 | 미정(합성 후 재료가 사라지는지, 시점은 언제인지) | 미정 |

### 1-2. 고정 레시피표 방식의 근거

하드코어 로그라이크에서 조합식이 전략 깊이를 만들려면 두 조건을 동시에 충족해야 한다.

- **발견의 재미**: 플레이어가 직접 조합을 시도하며 새 직업을 찾는 경험.
- **전략적 빌드**: 알고 있는 레시피를 목표로 재료를 모으는 집중 플레이.

고정 레시피표(STS의 유물 시너지, TFT의 아이템 조합 참고 결론)는 이 두 조건을 모두 충족한다.
변동 레시피(런마다 달라지는 방식)는 전략 집중이 어렵고 도감 발견의 의미가 줄어들어 채택하지 않는 방향이다(가정).

### 1-3. 비대칭성 (A+B ≠ B+A 여부)

| 방안 | 장점 | 단점 | 상태 |
|---|---|---|---|
| **대칭(A+B = B+A)** | 레시피 수가 절반. 학습 부담이 적음 | 조합 공간이 좁음 | 가정(현재 기준) |
| 비대칭(A+B ≠ B+A) | 레시피 수 두 배, 빌드 다양성 | 학습 비용·UX 복잡도 증가 | 미정(G3 비교 후 검토) |

**현재 가정: 대칭.** 재료 투입 순서와 무관하게 같은 결과를 낸다.
검증 세트(6+6)에서 비대칭이 필요한 경우가 나오면 재검토한다.

## 2. 레시피 개수 추정

### 2-1. 조합 수 상한 (재료 2개 기준, 대칭)

직업 N개에서 서로 다른 두 직업을 고르는 조합 수 = N(N−1)/2.

| 대상 직업 수 | 2개 조합 상한 | 3개 조합 상한 |
|---|---|---|
| 기본 직업 42 (T1, roster-plan.md 3절) | 861 | 11,480 |
| 기본 6 (검증 세트) | 15 | 20 |
| 기본 6 중 크로스오버 연결 직업 | 6 (roster-plan.md 5절 기준) | — |

전부 구현하는 것은 비현실적이므로 **계획된 계보**로 좁힌다(job-tree-plan.md 3절).

### 2-2. 실제 구현 목표 수

| 단계 | 레시피 수 | 비고 |
|---|---|---|
| 검증 세트(G0~G2) | **6개** | 기본 6개 세계 간 크로스오버 (5절 초기 후보) | 
| 최종 규모 목표 | **24개** | roster-plan.md 4절의 크로스오버 24개(가칭, G0 이후 확정) |
| 상한 설계 여유 | ~50개 | 추가 특수 레시피(3재료, 세계 내 특수 조합) 포함 시 |

**잠정 목표: 24개** (roster-plan.md 4절의 크로스오버 직업 표와 1:1 대응).
레시피마다 결과 직업 1개이므로 레시피 수 = 크로스오버 직업 수가 된다.

> 근거: 크로스오버 24개(가칭, 검증 세트 기준), 50개 상한은 솔로 개발 현실 제약상 가정. RUNE-24 시뮬레이션 전까지 미확인.

## 3. 재료 조건

### 3-1. 재료 분류 (잠정)

| 재료 유형 | 조건 | 결과 | 상태 |
|---|---|---|---|
| **크로스오버** | 서로 다른 세계(Realm)의 기본 직업 2개 | 크로스오버 직업(★1) | 잠정(roster-plan.md 4절) |
| **같은 계보 승급** | 같은 이름·단계의 직업 3개 | 한 단계 위 직업(★ +1) | 확정(design.md 「합성과 등급」) |
| **특수 조합** | 3재료 또는 특수 아이템 포함 | 미정 | 미정 |

### 3-2. 크로스오버 재료 조건 상세

- 재료는 **기본 직업(★1, 세계마다 3개)** 이어야 한다(roster-plan.md 3절 기준).
- 같은 세계의 기본 직업끼리는 크로스오버 조합이 아니라 **승급 계보** 경로를 따른다(가정).
- 상위 직업(★2 이상)을 재료로 쓰는 크로스오버는 **미정**. 결과 직업이 ★1 로 시작하므로 상위 직업을 낮추는 비용이 드는 점에서 일단 제외 방향(가정).
- 카드 조합식의 재료 조건은 유닛과 별개로 정해야 한다(미정).

### 3-3. 특수 재료 필요 여부

| 상황 | 필요 여부 | 비고 |
|---|---|---|
| ★1~★3 크로스오버 | 없음(기본 직업 2개만) | 잠정 |
| 3재료 크로스오버 | 미정 | 재료 2개 vs 3개는 7절 미결 사항 |
| 보스·유물 연동 레시피 | 미정 | 특수 유물을 재료로 쓰는 경우 검토 대상 |

## 4. 결과 직업 분류

### 4-1. 크로스오버 결과의 계보 귀속 (출처: job-tree-plan.md 13-3)

크로스오버 결과는 항상 **★1(T1)** 로 시작한다(design.md 「합성과 등급」, 확정).
이후 같은 이름 3개를 모아 승급하면 어느 계보로 이어지는지가 열린 문제다.

| 방안 | 내용 | 장점 | 단점 | 상태 |
|---|---|---|---|---|
| **A. 재료 계보 중 한 쪽** | 크로스오버 승급 시 재료 세계 중 하나의 T2 직업이 됨 | 직업 수 추가 없음. 계보가 단순 | 정체성 약화. 어느 계보인지 레시피마다 고정 | 제안(job-tree-plan.md 13-3) |
| B. 크로스오버 전용 계보 | 크로스오버마다 자기 T2~T7 계보를 가짐 | 직업 다양성 최대 | 직업 수 144개 추가 필요(24×6), 현실 비용 과다 | 미정, 규모 부담으로 잠정 제외 |
| C. 플레이어 선택 | 승급 시 어느 계보로 갈지 플레이어가 선택 | 빌드 자유도 높음 | UX·레시피 복잡도 증가 | 미정 |

**현재 제안(미승인): 방안 A.** 레시피마다 귀속 계보를 미리 정하고, 도감에 표시한다.

### 4-2. 티어별 크로스오버 배치 (job-tree-plan.md 13-2 기준 제안)

| 티어 | 직업 수(제안) | 크로스오버 포함 여부 |
|---|---|---|
| T1 | 66 (기본 42 + 크로스오버 24) | 크로스오버 24개 모두 T1 에 배치 |
| T2~T7 | 각각 20·14·10·6·4·2 | 승급 계보만 (크로스오버 귀속 결정 후 재산정) |

크로스오버가 T1 에 고정되므로 T2 이상의 직업 수는 재산정이 필요하다(job-tree-plan.md 10-3 미정).

## 5. 발견 시스템

### 5-1. 도감 기록 방식

| 항목 | 내용 | 상태 |
|---|---|---|
| 발견 트리거 | 처음 조합식을 완성한 순간, 도감에 자동 기록 | 잠정 |
| 처음부터 공개 | 레시피 일부는 공개. 나머지는 직접 발견해야 함 | 잠정(design.md 「합성과 등급」) |
| 도감 범위 | 런 사이 영구 보존(메타 진행 일부). 직업 해금과 함께 남음 | 잠정(difficulty-plan.md 4절) |
| 힌트 시스템 | 미정. 재료 한 쪽을 보여주고 나머지를 숨기는 방식 검토 | 미정 |

### 5-2. 처음부터 공개할 레시피 기준 (가정)

Super Auto Pets의 합성 공개 구조 참고 결론: 기본 조합(쉬운 재료, 역할이 뚜렷한 결과)은 처음부터 보여줘서 조합식의 존재를 플레이어에게 가르친다. 어려운 조합(재료 희귀, 역할 혼합)은 발견 보상으로 남긴다.

룬폴드 적용 원칙(가정):
- **검증 세트(6+6)의 6개 레시피 중 3개**: 처음부터 공개(튜토리얼 역할).
- **나머지 3개 + 최종 24개 중 나머지**: 발견 보상.
- 정확한 공개 비율은 G0~G2 플레이테스트 피드백으로 조정(미정).

### 5-3. 발견 보상과 도감 연동

```
처음 조합 성공 시:
  → 도감에 레시피 기록
  → "새 직업 발견!" 연출
  → 결과 직업 ★1 즉시 획득
```

도감은 런 사이에 보존되므로 **메타 진행**의 일부가 된다(difficulty-plan.md 참조).
발견 완료 직업 수로 해금 조건을 걸 수 있다(미정).

## 6. 구현 우선순위 — 검증 세트 6+6 초기 레시피 후보

검증 세트는 roster-plan.md 5절의 기본 6개 세계(서양 중세·무협·판타지·괴담·추리·게임)이다.

| # | 재료 A | 재료 B | 결과(가칭) | 역할 조합 | 공개 여부 |
|---|---|---|---|---|---|
| 1 | 기사(서양 중세, 전열) | 검객(무협, 근접) | 철갑 검협 | 전열 + 근접 → 방어형 근접 | 처음 공개 |
| 2 | 마법사(판타지, 마법) | 퇴마사(괴담, 제어) | 주술 마도사 | 마법 + 제어 → 마법·디버프 | 처음 공개 |
| 3 | 탐정(추리, 정보) | 퇴마사(괴담, 제어) | 심령 탐정 | 정보 + 제어 → 정보·약점 노출 | 처음 공개 |
| 4 | 용사(게임, 균형) | 기사(서양 중세, 전열) | 성검 용사 | 균형 + 전열 → 전열 딜러 | 발견 보상 |
| 5 | 검객(무협, 근접) | 탐정(추리, 정보) | 강호의 탐정 | 근접 + 정보 → 암살·정찰 | 발견 보상 |
| 6 | 마법사(판타지, 마법) | 용사(게임, 균형) | 마검사 | 마법 + 균형 → 근접 마법 딜러 | 발견 보상 |

**선정 근거:**
- 6개 세계 × 서로 다른 역할 조합 → 크로스오버가 새로운 역할 틈새를 만드는지 검증.
- 공개 3개: 전열+근접, 마법+제어, 정보+제어. 이 세 가지가 조합식 학습의 기본 패턴을 보여준다.
- 발견 3개: 공개 조합보다 재료 수집이 더 어렵거나(용사+기사) 역할이 더 복잡한(근접+정보) 조합.

## 7. 미결 사항

| # | 항목 | 내용 | 우선순위 |
|---|---|---|---|
| M1 | **재료 수 (2개 vs 3개)** | 기본 2개로 시작, 3재료 레시피를 추가할지. 3재료는 조합 공간이 넓어지지만 재료 확보 비용이 커짐. G0~G2 플레이테스트 후 결정(design.md) | 높음 |
| M2 | **실패 조합 처리** | 레시피표에 없는 조합을 시도하면 어떻게 되는가. 방안: ① 아무것도 안 됨(재료 유지) ② 재료 소멸 + 실패 연출 ③ 랜덤 결과(하드 로그라이크와 정합 여부 확인 필요) | 높음 |
| M3 | **재료 소모 시점** | 합성 확정 시 재료가 즉시 소멸하는가, 정리 화면 종료 시인가. 취소 가능 여부와 연동 | 중간 |
| M4 | **카드 조합식** | 유닛 조합식과 별개로 카드 조합식의 재료 조건을 정해야 함(design.md는 대상에 카드 포함, 규칙은 미정) | 중간 |
| M5 | **크로스오버 결과 귀속 계보** | 4절 방안 A·B·C 중 선택(사용자 결정 필요) | 높음 |
| M6 | **힌트 시스템** | 도감에서 미발견 레시피의 힌트(재료 한 쪽 공개 등)를 어느 시점에 줄지 | 낮음 |
| M7 | **비대칭 레시피** | A+B ≠ B+A 검토는 G3 이후. 검증 세트에서는 대칭으로 진행 | 낮음 |
| M8 | **발견 보상 비율** | 처음 공개: 발견 보상 = 3:3(검증 세트 가정). 최종 규모 24개에서의 비율은 플레이테스트 후 결정 | 낮음 |

- 레시피 1개당 제작 항목: 결과 직업 이름·도트·카드·번역. G0 단계는 6개만 제작.
- 재료 2개 vs 3개: G0 종이 프로토타입에서 반드시 시험해야 할 항목.
- 발견 방식(처음부터 공개 vs 도감 기록): G0 전 임시 결정 필요.

## 8. 참고 자료 (공개 자료 결론 요약)

- **슬레이 더 스파이어(STS) 아이템 시너지 결론**: 고정된 시너지 조합을 도감으로 공개하면 플레이어가 목표 빌드를 세울 수 있고, 반복 플레이 동기가 생긴다. 단, 시너지가 너무 강한 조합이 생기면 빌드 다양성이 줄어든다. 룬폴드 적용: 각 레시피의 결과 직업이 **역할 틈새를 차지**하도록 설계해 특정 조합 쏠림을 막는다.
- **TFT 아이템 조합 결론**: 재료 아이템 2개를 합쳐 완성 아이템을 만드는 구조는 학습 비용이 낮고 빌드 목표가 명확하다. 비대칭 조합(순서에 따라 결과가 다름)은 없고 대칭이다. 룬폴드 적용: 검증 단계에서 **대칭 2재료**를 기본으로 채택한 근거가 된다.
- **Super Auto Pets 합성 결론**: 합성의 일부를 처음부터 공개하고 나머지를 발견으로 남기면 초보자 진입과 고수의 발견 보상을 동시에 줄 수 있다. 층(티어)이 오를수록 강한 펫이 등장하는 구조는 룬폴드의 막(act)별 티어 창(job-tree-plan.md 11-3 B) 설계와 방향이 같다.
