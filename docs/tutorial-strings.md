# 튜토리얼·온보딩 및 문자열 동결 계획

## 1부: 튜토리얼·온보딩 설계 (RUNE-55)

### 원칙

강제 튜토리얼 없음. 첫 판 시작 전 선택지를 제공한다.

- **"안내받기"** — 첫 전투에 툴팁 오버레이를 표시한다.
- **"바로 시작"** — 안내 없이 즉시 플레이한다.

설정에서 언제든 안내를 재활성화할 수 있다.

### 안내 내용 (툴팁 8개)

| # | 주제 | 설명 |
|---|------|------|
| 1 | 격자 이동 | 격자 위 칸 선택 방법 (패드 D-패드 / 마우스 클릭) |
| 2 | 격자 이동 | 이동 가능 범위 표시 읽기 |
| 3 | 카드 사용 | 손패 카드 선택 방법 |
| 4 | 카드 사용 | 마나 비용 확인 및 사용 확정 |
| 5 | 합성 기본 | 카드 2장을 조합하는 방법 |
| 6 | 합성 기본 | 승급 결과 확인 방법 |
| 7 | 적 의도 | 적 행동 아이콘 읽기 |
| 8 | 적 의도 | 다음 턴 적 행동 예측 방법 |

- 툴팁 1개당 최대 2줄. 총 16줄.
- 패드·마우스 입력 모두 지원한다.
- M5a 번역 대상에 포함된다.

### 검증 기준

G2 플레이테스트(지인 3명)에서 외부 설명 없이 첫 판을 완주하는지 확인한다.

## 2부: 문자열 동결 계획 (RUNE-58)

### 동결 시점

M5.9(밸런스 잠금 마일스톤) 완료 시점에 문자열을 동결한다.

### 이유

밸런스 수치 변경은 카드 텍스트를 수반하며, 텍스트 변경은 번역 재작업을 유발한다.  
M5.9 이후 수치 변경을 금지함으로써 번역 재작업을 최소화한다.

### 동결 대상

- 카드 텍스트
- 유물 설명
- 이벤트 텍스트
- UI 문자열
- 업적 설명

### 동결 제외

버그 수정을 위한 소규모 텍스트 수정은 동결 대상에서 제외한다.  
변경 시 번역팀에 즉시 알린다.

### 처리 절차

1. M5.9 시작 시 문자열 파일 스냅샷 생성.
2. 이후 문자열 변경 발생 시 번역팀에 알림.
3. 출시 2주 전 최종 확인 및 빌드 반영 완료 확인.

### 번역 파이프라인

```
한국어 원본 동결
  → 영어 번역 의뢰
  → 검수
  → 빌드 반영
```

### 도구

Godot 내장 번역(CSV/PO 방식)을 사용한다. 뼈대는 M1에서 구현한다.
