# 2·3막 콘텐츠 + 카드·유물 설계 프레임워크 (RUNE-52+53)

실제 콘텐츠 수치는 M5a에서 결정하므로, 지금은 "무엇을 어떻게 만들 것인가"의 뼈대를 잡는다.

---

## 1. 2·3막 적 구성 프레임워크 (RUNE-52)

| 막 | 일반 적 | 엘리트 | 보스 | 특징 |
|---|---|---|---|---|
| 1막 | 8~10종 | 3~4종 | 1종 | 낮은 티어, 튜토리얼 역할 |
| 2막 | +5~7종 추가 | +2~3종 | 1종 | 중간 티어, 상태이상 등장 |
| 3막 | +3~5종 추가 | +2종 | 1종(최종) | 높은 티어, 복합 위협 |

### 적 설계 원칙

- 각 적은 역할 1개를 명확히 가짐 (돌격·방어·지원·견제·엘리트·보스)
- 2·3막 적은 1막 적의 "강화판"이 아니라 새로운 위협을 제시
- 보스는 특수 행동 패턴 + 페이즈 2 존재

---

## 2. 직업별 카드·유물 설계 프레임워크 (RUNE-53)

직업 1개당 기본 카드 3~5장 + 승급마다 +1장:

- **카드 역할 분류:** 공격 / 방어 / 버프 / 디버프 / 특수
- **직업 정체성은 카드 조합으로 표현**
- **유물 30종 목표 (M5):** 공격형 10 / 방어형 8 / 시너지형 7 / 특수형 5

### 콘텐츠 제작 순서 (M5a)

1. 검증 세트(6+6) 카드·유물 완성 → G2 테스트
2. 1막 전체 콘텐츠 → G3 테스트
3. 2·3막 콘텐츠 → M5a 완성
