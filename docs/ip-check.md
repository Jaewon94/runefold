# 직업 로스터 지식재산 점검 (RUNE-85)

**상태: 잠정** | 법률 조언이 아님 — 이 문서는 공개 자료를 바탕으로 한 내부 사전 점검이다. 최종 판단은 상표·저작권 전문가에게 맡긴다.

이 문서는 [roster-plan.md](roster-plan.md)의 세계 14개·직업 약 122개(가칭)를 이름 확정(RUNE-36) 전에 지식재산 위험 등급으로 분류한다.
룬폴드는 공개 저장소이며 Steam 출시를 목표로 한다. 이름이 확정되기 전에 위험을 파악해 변경 비용을 줄이는 것이 목적이다.

## 1. 점검 원칙

아래 내용은 공개 자료(특허청 안내, 법원 판례 요약, USPTO/EUIPO 가이드)를 바탕으로 요약한 것이다. 법률 조언이 아니다.

### 1-1. 상표법

- **상표는 등록 기준이다.** 사용 중인 이름도 미등록이면 상표권 분쟁에서 불리하다.
- **동종 업계(게임·소프트웨어) 안에서 혼동 가능성**이 침해 여부의 핵심 기준이다. 다른 업계(예: 음식, 의류)의 동일 상표와는 충돌 위험이 낮다.
- **일반 명사·기술 용어는 원칙적으로 상표 등록이 어렵다.** 그러나 특정 맥락에서 식별력을 얻은 경우는 예외다.
- **Korea(KIPRIS), US(USPTO), EU(EUIPO), Japan(J-PlatPat)** 각 관할권을 별도로 확인해야 한다. Steam은 전 세계 유통이므로 최소 한국·미국·EU 세 곳을 점검한다.

### 1-2. 저작권

- **저작권은 창작적 표현을 보호하고 아이디어 자체는 보호하지 않는다.** "기사", "마법사" 같은 장르 아키타입은 아이디어이므로 저작권 대상이 아니다.
- **특정 작품의 고유 캐릭터 이름, 설정, 대사, 외형 디자인**은 저작권 보호 대상이다.
- **신화·전통 설화·역사 속 인물·개념**은 공유 유산(퍼블릭 도메인)이다. 단, 현대 작품의 특정 해석·디자인은 보호된다.

### 1-3. 이 프로젝트의 적용 원칙 (roster-plan.md §7, 확장)

- 직업은 **장르의 아키타입과 트로프**로 만든다. 실존 작품의 캐릭터 이름, 고유 설정, 외형을 가져오지 않는다.
- 신화·전설·민담의 원형은 공유 유산이나, 특정 현대 작품의 해석·디자인을 모방하지 않는다.
- "게임" 세계의 용사·탱커·힐러는 장르 공통 어휘로 쓰되 특정 게임 직업 구성을 그대로 베끼지 않는다.
- 실존 종교·문화를 다룰 때는 존중과 민감성을 별도 점검한다.

## 5. 조사 방법 (RUNE-34 안내)

이름을 확정하기 전에 아래 데이터베이스를 직접 조회한다. 조회는 무료이며 회원 가입 없이 가능하다.

### 5-1. 한국 — KIPRIS

- URL: <https://www.kipris.or.kr>
- 경로: 상표 검색 → 상표명칭 검색
- 키워드: 직업 이름 그대로, 유사 키워드 변형 포함
- 확인 항목: 등록·출원 여부, 지정 상품/서비스류(게임은 41류)
- 담당 이슈: RUNE-34

### 5-2. 미국 — USPTO TESS

- URL: <https://tmsearch.uspto.gov>
- 경로: Basic Word Mark Search → Live/Dead 필터 활용
- 키워드: 영문 번역명 포함 검색 (직업명 한국어 확정 후 영문명 병행 조회)
- 확인 항목: 게임·소프트웨어 관련 IC 클래스(41, 42)

### 5-3. EU — EUIPO eSearch

- URL: <https://euipo.europa.eu/eSearch>
- 경로: Trade Marks → Text search
- 참고: EUIPO 등록은 EU 전체에 효력

### 5-4. 일본 — J-PlatPat

- URL: <https://www.j-platpat.inpit.go.jp>
- 경로: 商標 → 称呼検索(칭호 검색) 또는 文字商標検索
- 이유: 일본어권 IP(Dragon Quest, 음양사, 코난 등) 원출처 국가이므로 추가 확인

### 5-5. 인터넷 일반 조회 병행

- 검색엔진에서 직업명 + "게임", "만화", "소설", "애니메이션" 조합으로 동명 IP 존재 여부 확인
- Steam 스토어, GOG 검색으로 동명 타이틀 여부 확인
