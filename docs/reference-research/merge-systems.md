# 합성 승급 시스템 조사 (Super Auto Pets 중심, TFT / Hearthstone Battlegrounds 비교)

- 조사일: 2026-10-20 (아래 모든 "확인일"은 이 날짜)
- 방법: 공개 웹 자료(공식 위키, 팬 위키, 공식 공지, 가이드 글)만 열람. 게임 파일 접근 없음. 원문은 한국어로 요약했고, 이미지·에셋은 가져오지 않음.
- 한계: 모든 자료의 게임 버전이 명시돼 있지 않다. SAP 위키(wiki.gg)는 현재 버전 기준으로 보이나 버전 번호는 미확인이다. 세부 수치는 패치로 바뀔 수 있다.
- 확신도 기준: 높음 = 공식/위키 + 다른 출처 일치, 중간 = 단일 출처 또는 가이드 수준, 낮음 = 출처끼리 어긋나거나 오래된 글.

## 1. 합성 승급 규칙

### 1-1. Super Auto Pets

| 사실 | 출처 | 확신도 |
|---|---|---|
| 합성의 실제 동작은 "같은 펫 2마리를 하나로 합치기"이고, 결과물이 경험치(XP) +1을 얻고 원래 두 펫이 가진 XP도 합산된다. 그래서 레벨1 3마리 -> 레벨2가 되는 것처럼 보인다(0XP 2마리 합침 = 1XP, 거기에 1마리 더 합침 = 2XP). | https://superautopets.wiki.gg/wiki/Experience (2026-10-20) | 높음 |
| 레벨업 문턱: 레벨2는 XP 2, 레벨3은 거기서 3 더 필요(누적 5). 최대 레벨 3. 레벨1 복사본 기준으로 환산하면 레벨3까지 총 6마리분. | 같은 위키 Experience. 환산은 내 계산 | 높음(문턱), 중간(6마리 환산) |
| 출처 불일치: 팬 가이드(twoaveragegamers)는 레벨3 문턱을 "추가 3 XP"와 "6 EXP"로 둘 다 적어 모순된다. 오래된 버전 서술일 가능성. 위키 값(누적 5)을 채택하되 불일치로 기록. | https://www.twoaveragegamers.com/ultimate-guide-to-super-auto-pets-game-mechanics/ | 낮음(가이드 쪽) |
| 같은 이름만 합성 가능. 단, 일부 펫 능력으로 합성 규칙이 비튼다(예: 알파카는 구매한 펫을 레벨2 중간 지점까지 올려 필요한 복사본 수를 줄임). | https://superautopets.wiki.gg/wiki/Alpaca (검색 결과 요약), 가이드 | 중간 |
| 합성 시점: 플레이어가 직접 한다(상점의 펫을 팀의 같은 펫에 드롭하거나 팀 안에서 합침). 상점에서 같은 펫 구매 즉시 합치는 형태도 가능. 자동 합성이 아님. | 위키 Experience의 표현(합칠 때 선택), twoaveragegamers 가이드("Otter는 상점에서 바로 합칠 수 있음") | 중간 |
| 합성 시 능력치: 결과물은 두 펫 중 높은 능력치를 기준으로 +1/+1, 그리고 XP가 더 많은 쪽의 XP 1점당 +1/+1을 추가로 받는다. 예: 3/1 돼지 + 4/2 돼지 = 5/3(가이드 예시). | 위키 Experience, twoaveragegamers 가이드 | 높음 |
| 임시(전투 한정) 능력치도 합성 시 승계, 둘 다 있으면 큰 쪽 유지. | 위키 Experience | 높음 |
| 레벨업 시 능력(효과) 변화: 대부분 효과 수치가 레벨에 비례해 증가. 개미: L1 +2/+1, L2 +4/+2, L3 +6/+3. 예외도 있음: 부화하는 병아리는 L1은 앞 친구에게 임시 +3/+3, L3은 +1 XP(영구 +1/+1 효과) 식으로 질적으로 달라짐. | https://boyter.org/posts/brute-forcing-super-auto-pets (개미), https://superautopets.wiki.gg/wiki/Hatching_Chick (검색 결과 요약) | 중간 |
| 레벨업 보상: 레벨업 때 현재 상점 티어 +1 티어의 무작위 펫 2개 중 1개를 고를 수 있게 상점에 나타난다(구매는 하나만). 레벨2끼리 합칠 때는 보상 없음. 상점 슬롯에 빈자리가 있어야 나타난다. | https://superautopets.wiki.gg/wiki/Experience, https://www.twoaveragegamers.com/ultimate-guide-to-super-auto-pets-game-mechanics/ | 높음(보상 존재), 중간(2개 중 1개: 위키 한 곳) |
| 최대 레벨(3) 이후 XP를 받으면 레벨은 그대로이고 XP 1점당 +1/+1만 받는다. | 위키 Experience | 높음 |
| 다른 XP 획득원: 초콜릿(음식), 졸음 알약+복어 조합, 전투 중 임시 XP(진저브레드맨 등). 합성 외에도 XP를 채울 수 있다. | 위키 Experience | 높음 |
| 등급(티어)과의 관계: 펫의 티어(1~6)는 상점 출현 구조를 가르는 축이고, 합성 단계(레벨 1~3)는 별개 축. 레벨이 오르면 상점에 한 티어 위 펫이 보상으로 뜸(두 축이 이어지는 유일한 접점). 판매가는 펫의 레벨과 같고 XP와 무관(레벨1=1, 레벨2=2, 레벨3=3). | https://superautopets.wiki.gg/wiki/Shop (판매가), 가이드 | 높음 |
| 위키 The Basics에 "합성(merge) 비용 3골드"라고 적혀 있으나, 같은 위키 Shop에서 구매 비용이 3골드라고만 하므로, 아마 "복사본을 사서 합치는 비용=구매가"를 뜻하는 서술일 가능성. 합성 동작 자체에 별도 비용이 있는지는 미확인. | https://superautopets.wiki.gg/wiki/The_Basics | 낮음 |
| 능력치 상한: 대부분 50, 일부(베히모스)는 100. | The Basics | 중간 |

| 사실 | 출처 | 확신도 |

| 이상 현상(Anomaly) 모드에서는 2개로 골든이 되고 보상은 발견 대신 코인(Mr. Tick-Tock, False Idols). | 검색 결과 요약(icy-veins 계열 / blizzardwatch https://blizzardwatch.com/?p=172536) | 중간 |

## 2. 합성이 만드는 판단과 밸런스 문제, 설계 교훈

| 사실 / 관찰 | 출처 | 확신도 |
|---|---|---|
| SAP 가이드: 초반에는 레벨업을 서두르지 말고 복사본을 여러 개 들고 있는 편이 낫다("크리켓 3마리와 말 2마리가 레벨2 크리켓 + 반쯤 키운 말보다 낫다"는 취지). 즉 "합성 안 하고 두 슬롯을 쓰는" 선택과 "합쳐서 슬롯을 비우는" 선택이 맞물려 있다. | https://gamepretty.com/super-auto-pets-beginners-guide/ , https://www.twoaveragegamers.com/above-average-super-auto-pets-beginners-guide/ (후자는 직접 열람 410 실패, 검색 결과 요약만 있음) | 중간 |
| SAP: 레벨업은 상점에 한 티어 위 펫을 띄워 주므로, 합성 시점을 조절해 강한 펫을 한두 턴 빨리 구하는 용도로 쓴다. | gamepretty 가이드, 검색 결과 요약 | 중간 |
| SAP: 남은 전투가 1~2번이면 합성/장기 투자를 하지 말고 임시 버프를 쓰라는 조언. 승급은 장기 투자라 시기가 있다는 뜻. | 위 가이드 | 중간 |
| SAP: 슬롯 압박은 팀 5칸. 합성은 칸을 하나 비워 주면서 능력을 키우므로 5칸 제한 하에서 자연스러운 압축 수단이 된다(내 해석). 합성이 주는 "칸 절약"은 위키에 명시된 설계 의도는 아님. | The Basics(5칸), 내 해석 | 팀 5칸: 높음, 해석: 낮음 |

| TFT: 벤치 9칸과 한정된 풀(5비용 9개)이 만드는 긴장. "쓸 유닛만 벤치에 두라"는 플레이어 조언이 흔하다. 상대와 같은 유닛을 경쟁하면 풀이 줄어 3성이 어려워진다. | https://bunnymuffins.lol/using-8-heuristics-to-improve-at-tft/ , https://metabot.gg/en/TFT/guides/tft-star-levels-champion-pool-explained | 중간 |
| TFT 설계 장치: 합성 조건이 충족되면 벤치가 가득 차도 구매 가능 -> 벤치 압박이 합성 자체를 막지 않게 한 규칙. 이를 도입한 개발 의도에 대한 Riot 발언은 찾지 못함. | LoL 위키 Arenas | 규칙: 높음, 의도: 미확인 |
| HSBG: 트리플은 즉시 자동. 보상으로 발견 한 번을 주어 3개를 모으는 데 쓴 칸/골드를 보상으로 일부 환급하고, 승급이 곧 티어 진행과 이어지게 함. | 공식 공지 | 높음(규칙), 중간(해석) |
| SAP 쪽 개발자 글/설계 회고(postmortem)는 찾지 못함. 공개된 것은 위키와 가이드뿐. | 검색 결과(개발자 글 없음) | 미확인 |
| 팬 시뮬레이션 글(2021~22년 초기 버전 기준 추정): 강한 펫과 그걸 키워 주는 버퍼를 짝지으면 초반 승률이 좋았다. 후반에는 계속 키울지 능력 센 펫으로 갈아탈지가 불분명하다고 서술. | https://boyter.org/posts/brute-forcing-super-auto-pets | 낮음(옛 버전) |

## 5. Runefold 미결 사항에 대한 시사점 (사실이 아니라 내 해석)

### 5-1. 합성 자동 vs 수동

- 비교 사례: SAP는 수동(합칠 때 XP 지분과 보상이 의미 있어서 타이밍이 전략 요소), TFT와 HSBG는 자동(타이밍이 아니라 "모으는 것"이 전략 요소).
- Runefold는 "같은 이름 3개 -> 1개, 단계 1->3" 구조라서 한 번에 단계가 1->3으로 점프한다(SAP나 TFT처럼 중간 단계 없음). 중간 단계가 없으니 "반쯤 합성된 상태"는 존재하지 않고, SAP식 XP 지분 누적 판단이 생기지 않는다. 그렇다면 합성 타이밍 판단의 재미는 "3개가 모이기 전에 쓸지 말지"로 옮겨 가야 한다.
- 자동 합성은 실수(원치 않는 합성) 방지와 UI 단순화에 유리하고, 수동은 "일부러 합성을 미루는" 전략(SAP에서 복사본을 들고 있는 편이 나은 경우)을 허용한다. 카드 로그라이크에서 합성을 미루는 의미가 있는지(합치기 전 카드를 개별로 써야 하는 이유가 있는지)가 선택 기준이 된다.
- 절충안 후보: 조건이 충족되면 자동으로 "합성 가능" 표시만 하고 확정은 플레이어가 하는 방식(원치 않는 합성 방지 + 타이밍 선택 유지). 이 방식을 쓴 사례는 이번 조사에서 확인하지 못함.

### 5-2. 소대 정원과 대기석 수

- SAP: 팀 5칸, 상점 최대 6칸(가이드 수치). TFT: 벤치 9칸. HSBG: 필드 최대 7.
- 3개 합성에는 "3개를 모아 둘 자리"가 필요. TFT는 벤치 9칸과 "벤치가 가득 차도 합성에 필요한 구매는 가능" 규칙으로 압박을 완화함. 대기석이 정원보다 얼마나 커야 하는지의 직접 근거는 없으나, 합성 재료 3개 + 이미 쓰는 칸이 겹치므로 대기석은 최소 "서로 다른 합성 후보 2종 x 2개 = 4칸" 정도가 필요하다는 것이 내 추정이다(검증 필요).
- 합성 직전 재료를 대기석 밖에서 구매 가능하게 하는 TFT 규칙은 그대로 가져올 만하다.

### 5-3. 단계별 능력치 증가폭

- SAP: 레벨마다 효과 수치가 선형으로 증가하는 경우가 흔함(개미 +2/+1 -> +4/+2 -> +6/+3 = 배수 1/2/3). 합성 때는 별도로 +1/+1 가산. 레벨3까지 필요한 재료는 6개분이라 효과 3배는 재료 대비 보수적.
- TFT: 한 사례에서 2성 체력 x1.8, 3성 x3.24, 3개 -> 9개를 쓰므로 단위 재료당 효율은 3성에서 오히려 떨어진다(3.24/9 vs 1.8/3). 높은 단계로 갈수록 "재료 대비 효율"을 낮추는 설계. 단 이 수치는 한 챔피언 기준 계산이라 일반 규칙으로 확정할 수 없음.
- HSBG: 골든 = 대략 2배 + 능력 강화, 재료 3개. 재료 3개당 2배(약 0.67배/개)로 효율이 낮은데 보상(발견)이 함께 주어짐.
- Runefold는 3개 -> 1개로 1->3단계라 재료 3개에 "단계 2개를 건너뜀". 단계 3의 증가폭을 정할 때 위 세 사례가 재료 N개당 총능력 약 2~3.24배 수준이므로, 3개 재료를 쓰는 Runefold의 단계 3은 단순 비례(3배)보다 낮게 시작해(예: 2~2.5배) 시험하는 것이 합리적이라는 정도의 시사점. 구체 수치는 플레이 관찰 후 정해야 함.

### 5-4. 등급(희귀도)과 단계를 별개 축으로 둔 점

- SAP도 "티어(상점 해금)"와 "레벨(합성 단계)"이 별개 축이고, 레벨업 보상이 두 축을 잇는다(한 티어 위 펫 제공). Runefold도 합성 완료 보상이나 단계가 상점/보상 등급과 맞물리는 지점이 있어야 두 축이 의미가 있는지 설계해 볼 가치가 있다.
- HSBG의 트리플 보상(발견)도 같은 목적: 합성이 곧바로 티어 진행 가속이 된다. 재료를 모은 비용을 보상으로 환급하는 구조의 사례.

### 5-5. 한 판 길이

- SAP는 10승 목표, 무타이머, 최소 10턴으로 약 10~30분 범위. Steam용 로그라이크는 한 판이 이보다 길 수 있으나, 합성 구조(3개 모으기)는 최소 몇 턴/층이 필요한지에 직접 영향. 합성 자체를 의미 있게 하려면 3개를 모을 수 있는 최소 3~5턴 이상이 필요하다는 내 추정이 있음(검증 필요).

## 6. 미확인 목록

1. SAP 현재 버전 번호와 각 수치가 해당하는 버전.
2. SAP 현재 버전의 턴별 펫/음식 상점 슬롯 수 (위키에 없음, 가이드는 최대 6, 초기 팬 글은 다르게 서술).
3. SAP 팀 크기 5칸 외의 서술("1턴 최대 3마리")이 정확히 무엇을 가리키는지.
4. SAP 합성 동작에 골드 비용이 별도로 있는지(위키 The Basics의 "3골드" 서술의 의미).
5. SAP 레벨별 능력 증가가 전 펫에서 선형인지(개미, 병아리 사례만 확인).
6. SAP 개발자의 합성/레벨 시스템 설계 의도 (개발자 인터뷰/postmortem 못 찾음).
7. SAP 레벨별 기본 능력치 변화(합성 가산 외에 레벨 자체가 기본 스탯을 바꾸는지).
8. TFT 별 단계 능력치 배수의 공식 규칙 (한 챔피언 계산만 있음), Riot의 벤치/풀 설계 의도.
9. TFT 챔피언 풀 크기 정확 값 (세트마다 다르고 출처 값이 서로 다름: 29/22/18/10/9 근사 vs 30/25/18/10/9).
10. HSBG 골든 재승급 불가 여부의 공식 확인, 현재 필드/손 크기, 평균 한 판 시간의 공식 수치.
11. 라운드 1회 길이(SAP 상점 단계 + 전투)의 공식 또는 측정 수치.
12. Icy Veins HSBG 가이드, twoaveragegamers 입문 가이드는 직접 열람 실패(403, 410). 해당 내용은 검색 결과 요약에 의존.
