# 라피스(Lapis) 참고작 조사 - 1단계

조사일: 2026-10-20 / 방법: WebSearch, WebFetch만 사용 (게임 파일 다운로드/설치/분해 없음)

## 0. 결론 요약

- **"타일 격자 전술 전투 + 카드/로그라이크"에 정확히 맞는 'Lapis' 게임은 확인하지 못했다. 대상 식별: 사용자 확인 필요.**
- 가장 유명한 동명 후보 'Lapis x Labyrinth'는 횡스크롤 액션 RPG라서 격자 전술 게임이 아니다.
- 이름과 "8x8 격자 + 덱빌딩 로그라이크" 조건이 겹치는 것은 'Lapistasia'(2026, Steam)뿐이다. 다만 전술 전투가 아니라 Balatro식 블록 퍼즐 덱빌더로 보이고, 유닛·이동·사거리 설명이 스토어 페이지에 전혀 없다.
- 따라서 사용자가 말한 '라피스'가 이 중 하나인지, 이름을 다르게 기억하는지 확인해야 한다. 아래 표는 후보별로 확인된 사실만 적었다.

## 3. Runefold에 시사하는 점

주의: 대상이 불확실하고 확인된 전술 격자 정보가 거의 없으므로 아래는 "후보 게임에서 확인된 것"과 "일반 설계 제안"을 구분한다.

확인된 사실에서 나온 시사점:
1. **조건이 어려울수록 보상이 큰 유물(Lapistasia 방식)** 은 Runefold의 시너지 설계에 쓸 만하다. 예: "엄폐 뒤에서 처치", "고저차 이점 공격", "적 예고 칸을 비운 채 턴 종료" 같은 조건부 유물. 조건이 보이면 플레이어가 계획을 세울 수 있다.
2. **유물 수의 규모:** 데모 약 80, 정식 150 이상이라는 수치는 시너지 풀 규모의 참고치다. Runefold 1차 출시 범위는 훨씬 작게 잡는 것이 현실적이다(제안).
3. **보스가 규칙을 바꿔서 전투를 퍼즐로 만든다**(Lapistasia). Runefold의 적 행동 예고와 잘 맞는 패턴이다.
4. **HP를 대가로 지불하는 비밀 상점**은 위험-보상 선택을 적은 구현 비용으로 만든다.
5. **장비 점수 총량 제한(Lapis x Labyrinth)** 은 "무엇을 가져갈지"를 강제하는 단순한 장비 제약 방식이다. 유닛 3~4명 구조에서 파티 전체 점수 한도로 응용할 수 있다.
6. **짧은 미션 단위(15~20분, 검색 요약 기준)** 는 한 판 30~45분 목표와 비교할 때 전투 1회를 짧게 가져가야 한다는 감각 참고치다. 신뢰도 낮음.

일반 설계 제안(참고작에서 확인되지 않음):
- 격자 전술 요소(엄폐, 고저차, 사거리 모양, 이동+행동, 적 행동 예고)는 이 후보들에서 확인된 것이 없다. 이 부분은 별도 참고작(예: 다른 전술 로그라이크)으로 조사해야 한다.

## 4. 미확인 목록

- 사용자가 말한 '라피스'가 실제로 어느 게임인지
- 전술 격자 전투의 유닛 수, 턴 구조, 행동 방식, 사거리 모양, 지형 요소 (모든 후보에서 미확인)
- Lapistasia의 한 판 소요 시간, 층당 노드 수, 전투 길이
- Lapistasia의 등급/합성 규칙, "Factor"의 구체적 종류
- Lapistasia 정식 출시일과 가격, 한국어 지원 계획
- Dragon Lapis의 전투가 격자인지 여부와 파티 규모
- Lapis x Labyrinth의 장비 시너지, 직업별 특징 (rpgamer, gematsu 일부는 403 오류로 접근 못함)
- 드래곤&라피스, Lapis Re:LiGHTs의 전투 구조 (격자 여부)
- Lapis x Labyrinth의 "15~20분" 수치는 검색 결과 요약으로만 보았고 원문 직접 확인 못함

## 5. 2단계(플레이 관찰) 때 확인해야 할 질문

먼저 사용자에게:
1. '라피스'는 어느 플랫폼(Steam, iOS, Android, 콘솔)에서 보았고, 스토어에 어떤 이름으로 나왔는가? 스크린샷이나 링크가 있는가?
2. 도트 그래픽인가, 애니풍인가? 격자 위에서 캐릭터를 직접 움직이는가?

대상이 Lapistasia로 확인되면 (공개 데모만 해당, 사용자가 직접 플레이하는 범위):
3. 블록 배치 한 번이 한 턴인가? 적은 어떻게 행동을 예고하는가?
4. 한 층의 전투 수와 소요 시간, 5층 한 판의 총 시간은?
5. 블록 강화(Factor)의 단계와 등급 구조는? 유물 조건의 난이도-보상 곡선은 어떤가?
6. 유닛 전술 요소(이동, 사거리, 지형)는 정말 전혀 없는가?

대상이 다른 게임이면 항목 1~4를 그 게임으로 다시 조사한다.
