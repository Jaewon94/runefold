## 5. Runefold에 가져올 만한 점 (참고용, 그대로 따를 필요 없음)

1. **행동마다 게이지를 깎는 구조의 변형.** 라피스는 행동 종류별로 대기 시간이 쌓이는 틱 구조다. Runefold가 카드/에너지 기반이라면 "카드마다 에너지 비용 + 일부 카드에 쿨다운(다음 턴 재사용 지연)"을 얹어 이동/공격/스킬의 값을 다르게 만드는 아이디어로 참고할 만하다. 실시간 자체는 Runefold의 턴제 카드 구조와 안 맞을 수 있다.
2. **4인 지휘관 편성.** 파티 4명(주 1 + 보조 3)은 타일 전투에서 읽기 쉬운 규모다. 카드 로그라이크의 파티 크기 기준으로 참고.
3. **등급 단계(단)가 외형 + 스킬 1개를 동시에 주는 방식.** 승급 보상이 시각 변화와 능력 추가를 함께 줘서 성장이 눈에 보인다. Runefold의 3->1 합성 결과물에 "도트 외형 변화 + 효과 1개 추가"를 붙이는 설계에 참고.
4. **같은 재료 N개 -> 1개 제련.** 광석 10개 -> 보석 1개는 3->1 합성의 원형과 비슷하다. 다만 라피스 쪽 확률 하락(+3~-2) 같은 위험 요소는 로그라이크의 짧은 판에서는 불쾌할 수 있어 가져오기 전 신중히.
5. **시나리오 스테이지 구조.** 대형 MMO 요소는 버리고 "시나리오 = 스테이지 묶음 + 대련장(비동기 PvP 가능성)"만 보면, Runefold의 런 구조와 별개로 메타 콘텐츠 아이디어가 된다.
6. **반면교사.** 강화 실패 시 파괴와 복잡한 재화 체계, 업데이트 지연에 대한 불만이 문서에 나타난다. 유물/합성 규칙은 단순하고 예측 가능하게 두는 편이 안전.

주의: 라피스는 카드 게임이 아니며, 3->1 합성과 유물 시너지는 확인되지 않았다. Runefold 설계의 직접 근거로 쓸 수 있는 것은 타일 + 소규모 파티 + 승급 보상 설계 정도다.

## 6. 미확인 목록

- 2026-10 현재 한국 서비스 지속 여부, 현재 운영사(엠게임 vs 보노게임)의 확정
- 타일 맵 크기, 전투 중 양측 유닛 수, 전투 1회 평균 시간
- 행동별 틱 소모 수치, 병종 상성, 지형/방향/사거리 규칙
- 3->1 같은 합성 규칙 존재 여부(현재까지는 없음으로 보이나 단정 불가), 장비 세트/유물 시너지
- 일본판 정확한 오픈일(2006-03-22 vs 2006-05-18 상충)
- 공식 사이트와 나무위키 하위 문서 전문(일부는 403 또는 요약만 확인, thewiki.kr은 403)
- 사용자가 말한 "온라인 게임이고 힌트는 네오 다크세이버"가 이 게임이 맞는지 최종 확인(사용자 확인 필요)
