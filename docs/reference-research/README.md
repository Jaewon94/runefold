# 참고작 조사 (1단계: 공개 자료) — 2026-10-20

Runefold 설계에 가져올 만한 점을 찾기 위한 참고작 조사다. 따라 만들겠다는 뜻이 아니라 **차용 후보 목록**이다.

- 방법: 공개 웹 자료(위키, 스토어 페이지, 패치노트, 인터뷰, 가이드)만 읽었다. 게임 파일은 받거나 설치하거나 분해하지 않았다.
- 모든 파일은 우리 말 요약이다. 사실마다 출처 URL, 확인일, 확신도를 적었다. 모르는 것은 '미확인'으로 두었다.
- 위키 일부(Fandom 등)와 GDC 원문은 접근이 막혀 검색 요약에 기댄 수치가 있다. 확신도를 파일마다 표시했다.
- 상대 게임의 코드 조각·에셋·화면 캡처는 이 저장소에 두지 않는다. 구조 분석(REA)은 별도 프로젝트에서 하며, 2·3a단계는 아직 하지 않았다.

## 취합: 가져올 만한 점

**합성·등급**
- TFT는 3개를 자동 합성하고 2성 3개(총 9개)가 3성이다. Runefold의 3→1, 최대까지 9개와 같은 구조다. Super Auto Pets의 경험치 지분 누적은 적용하지 않는다.
- SAP는 티어(상점 해금)와 레벨(합성 단계)이 별개 축이고 레벨업 보상으로 두 축을 잇는다. 등급과 단계를 분리한 설계의 근거다.
- 합성 자동/수동(미결): 합성은 플레이어가 확정하고 화면에는 '합성 가능'만 표시하는 절충안을 제안받았다. 같은 사례는 못 찾았다(우리 해석).
- 단계별 증가폭(미결): 재료 대비 총능력이 약 2~3.24배(3.24배는 챔피언 하나의 값). 3단계는 단순 3배보다 낮게 시작하고 수치는 플레이 관찰 뒤에 정한다.
- 아르카나 택틱스는 별 1~5성이 희귀도와 합성 단계를 겸하는 모바일 자동 전투 게임이라 합성 참고작으로는 맞지 않다.

**전투**
- 소대는 3~4명이 맞다. Into the Breach는 메카 3기(8x8), XCOM은 최대 6명이며 개발진은 소대가 크면 한 수의 의미가 줄어든다고 판단했다.
- 이동은 무료·취소 가능, 행동은 취소 불가로 나눈다. Floppy Knights는 이동을 카드로만 하게 해 이동이 막히는 불만이 가장 컸다. 이동을 스탯으로 두는 설계가 이를 피한다.
- 적 행동 예고: Into the Breach(공격 타일·순서 표시), Wildfrost(카운터), 라피스(틱 게이지)가 모델이다. XCOM에는 직접 참고할 모델이 없다.
- 밀기·충돌·지형 즉사가 Into the Breach 전투 깊이의 핵심이므로 밀기 계열 카드를 유지한다.
- 초기 요구사항 후보: 되돌리기, 사거리 미리보기, 적 턴 건너뛰기, 스포너 예고. Floppy Knights 불만의 대부분이 UX였다.
- XCOM 설계 교훈: 복잡한 시스템은 되지만 번거로운 시스템은 안 된다. 화면에 표시한 확률은 정확해야 한다.

**카드·유물·한 판**
- 슬레이 더 스파이어의 에너지 3, 드로우 5가 Runefold의 틀과 같다. 드로우·에너지 환급은 처음부터 상한을 둔다(Floppy Knights의 무한 콤보 사례).
- 보스 유물은 '에너지 +1 + 부담' 구조가 일관된다(1편에서 확인한 4종).
- 유물 형태(영구 장착형 대 런 전역 규칙형)를 먼저 정한다. Wildfrost는 영구 장착형(참)이다.
- 보상·가격 출발점(슬레이 더 스파이어 1편): 일반 전투 보상 등급 60/37/3, 엘리트 50/40/10, 카드 가격 약 1:1.5:3. Steam 가이드와 수치가 어긋나는 곳이 있어 파일에 병기했다.
- 한 판 길이: 슬레이 더 스파이어 숙련자 31~43분, Wildfrost 30~60분(요약 기반), TFT 20~35분. 격자 전투는 노드당 더 길 수 있어 12노드보다 줄일 가능성이 있다. 전투 하나의 턴 수는 공개 자료가 없어 직접 재야 한다.
- 난이도: Wildfrost는 기본을 관대하게, 어려움은 선택형으로 옮긴 뒤 평가가 오르는 사례다.
- 라피스: 승급 때 외형 변화와 능력 1개를 함께 주는 방식은 참고할 만하다. 강화 실패 시 장비 파괴는 피한다.
