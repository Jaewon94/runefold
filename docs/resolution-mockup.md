# 해상도 목업 결과 (RUNE-42, 2026-10-21)

기준 해상도를 코드 전에 정하려고, 같은 화면(8×8 격자, 파티 4명, 적 의도, 손패 5장)을 480×270 과 640×360 으로 그려
한글 카드 텍스트가 읽히는지 봤다. 이미지는 `docs/assets/` 에 있다(도구는 임시 스크립트, 저장소에 없음).

## 결과

| 기준 해상도 | 글자 높이 | 읽힘 | 카드 한 줄 글자 수 | 비고 |
|---|---|---|---|---|
| 480×270 | 8px | 어려움("명중"이 "정운"처럼 뭉개짐) | 약 11자 | 본문에 쓰기 어렵다 |
| 480×270 | 10px | 읽힌다 | 약 9자 | 카드 폭 90px. 설명 두 줄을 넘기면 넘친다 |
| 640×360 | 10px | 읽힌다 | 약 12자 | 카드 폭 120px. "사거리 1, 명중 90%, 피해 4"가 한 줄에 들어간다 |

- **Steam Deck 정수 배율:** 480×270 은 ×2 = 960×540 으로 1280×800 의 가로 75%만 쓴다(×3 은 1440 이라 넘친다).
  640×360 은 ×2 = 1280×720 이어서 가로를 꽉 채운다(위아래 40px 여백). 1080p 는 ×3, 1440p 는 ×4, 4K 는 ×6 으로 모두 딱 맞는다.
  480×270 은 1080p ×4, 4K ×8 이지만 1440p 는 정수 배율이 안 맞는다.
- **Deck 글자 요건(화면 높이 9px 이상):** 두 기준 모두 ×2 에서 10px 글자가 20px 이 되므로 문제없다.
- **카드 텍스트:** 480×270 을 쓰려면 사거리·명중·피해는 아이콘 + 숫자로 표시하고 글자는 카드 이름과 키워드만 두는 것이 안전하다.
- **글자 높이 최소 기준(잠정):** 본문 10px 이상, 8px 이하는 설명 텍스트에 쓰지 않는다.

## 한계
- 임시로 시스템 폰트(Apple SD Gothic Neo)를 안티앨리어싱 없이 그렸다. 실제 한글 비트맵 도트 폰트가 아니므로 가독은 근사치이며,
  숫자 1/I, 5/S 처럼 헷갈리는 모양은 이 폰트의 특성이다. 도트 한글 폰트 후보는 라이선스를 직접 읽고 대장에 올린다(미확인).
- 레이아웃은 개략 배치이고 실제 UI 디자인이 아니다.
- 타일 16px 은 그대로 두고 비교했다. 640×360 에서도 격자 8×8(128px)이 화면 높이의 36%라 손패 공간이 더 넓다.

## 권고
- **640×360 을 기준 해상도로 바꾸는 것을 권한다.** 한글 카드 텍스트 공간이 25% 더 넓고 Steam Deck 에 정수 배율로 꽉 맞는다.
  타일 16px 과 도트 에셋 크기는 그대로이고, 변하는 것은 UI 가용 공간이다.
- 480×270 을 유지하면 카드를 아이콘 + 숫자 중심으로 설계해야 하고 Deck 에서 여백이 커진다.
- 결정은 DEC06(기준 해상도 480×270 확정, 타일 16px 잠정)을 바꾸는 일이라 사용자 확인이 필요하다.

## 타일 크기 비교 (640×360, 2026-10-21 추가)

`docs/assets/mockup-640x360-tiles-16-24-32.png`. 격자는 8×8 이고 손패 카드는 같은 5장이다.

| 타일 | 격자 높이 | 손패 카드 높이 | 특징 |
|---|---|---|---|
| 16px | 128px | 208px | 카드 공간은 넉넉하지만 캐릭터가 작아 승급 외형 변화를 보여 주기 어렵다 |
| 24px | 192px | 144px | 균형은 좋지만 24px 는 흔치 않은 규격이라 무료 에셋을 늘려 쓰면 뭉개진다(가정, 미확인) |
| 32px | 256px | 82px | 캐릭터가 크고 Deck ×2 에서 타일이 64px 로 선명하다. 카드는 이름 + 아이콘·숫자 3줄 정도로 간결해야 한다 |

- **잠정 결정(2026-10-21): 640×360 + 타일 32px.** "네오 다크세이버 느낌"과 "단 성장 때 외형이 바뀐다"는 요구에 맞는다.
- **확정 조건:** 무료 에셋 조사(RUNE-20)에서 32px 팩(상업 이용 가능)이 충분히 있어야 한다. 부족하면 16px(카드 공간 넉넉)로 돌아간다.
- 아트가 없는 지금은 바꾸는 비용이 작다(프로젝트 설정 값 하나). 첫 도트 에셋을 들이기 전에 확정한다.
