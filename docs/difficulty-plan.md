# 난이도 설계 계획: 하드 로그라이크 (2026-10-27)

사용자 말씀(2026-10-27): **하드 로그라이크 게임처럼 구하는 것은 랜덤으로 구하고, 죽으면 정말 사라지게 하는 어려운 게임.** 이 문서는 계획 문서이며
방향은 확정, 세부(특히 "정말 사라지는" 범위)는 사용자 답 대기다. 정본은 Confluence 에 둔다.

## 1. 정의 (사용자 방향)
- **획득은 랜덤:** 보상, 상점, 이벤트에서 얻는 직업·카드·유물이 무작위다. 시드를 고정하면 재현되는 결정론 규칙(SeededRng)을 쓴다.
- **죽으면 정말 사라진다:** 유닛이 쓰러지면 영구히 소멸하고, 런이 끝나면 런에서 얻은 것은 사라진다. 이미 정한 "영구 손실"(DEC28)과 같은 방향이다.
- **어려운 게임:** 쉬운 구제 장치를 기본으로 넣지 않는다. 종이 프로토타입의 사망 변형 V1(순수 영구 손실)이 기본형이고 V2·V3(완화)는 시험용 변형이다.

## 2. 파급 (설계에 미치는 영향)
| 영역 | 영향 |
|---|---|
| 직업 100개 이상 | 한 판에서 만나는 직업은 일부. 랜덤 획득이라 빌드 다양성이 생긴다. 하위 티어가 주력으로 버텨야 하므로 밸런스 8-2(job-tree-plan.md)가 필수 |
| 합성 투자 | 같은 것 3개를 모아 키운 유닛이 확률 명중 한 번으로 사라질 수 있다. 합성 투자 보호 장치(정보 공개, 위험 선택)가 필요 |
| 티어 구조 | 계정 진행으로 티어를 해금하는 선택지(job-tree-plan.md 2절 C)는 "정말 사라진다"와 충돌할 수 있다 |
| 한 판 길이 | 영구 사망으로 일찍 끝나는 판이 많다. 실패 후 즉시 재도전할 수 있는 판 길이(30~45분 목표)가 중요 |
| 종이 프로토타입 | V1 을 기본형으로 두고 억울함을 더 엄격히 본다 |

## 3. 어려워도 억울하지 않게 하는 장치 (제안, 시험 전)
하드 로그라이크의 "어려움"과 "억울함"은 다르다. 선택과 정보로 어렵게 만들고, 운으로 억울하게 만들지 않는다.
- **정확한 정보:** 표시한 확률은 항상 정확(이미 원칙), 적 행동 예고, 위험한 선택은 위험을 미리 보여 준다.
- **재현성:** 시드 고정, 시드 공유, 일일 도전 같은 같은 조건 비교.
- **위험·보상 선택:** 더 위험한 길에 더 큰 보상을 준다. 선택은 플레이어가 한다.
- **획득 풀 설계:** 연속 불운을 값싼 보정(조작이 아니라 풀 구성, 하위 티어 가치)으로 줄인다.
- **빠른 재시작:** 실패 후 바로 다시 시작할 수 있다.
- **지식으로만 진행(선택지):** 도감처럼 플레이어의 지식이 쌓이는 것은 허용하고 전력(스탯·유닛)은 이월하지 않는다.

## 4. 사용자에게 필요한 답
1. **"정말 사라진다"의 범위: 확정(사용자 2026-10-27).** 런 중 쓰러진 유닛은 영구 소멸하고, 런이 끝나면 런에서 얻은 전력은 이월되지 않지만 **도감과 직업 해금은 남는다.** **(2026-10-28 수정) 창고에 맡긴 일부 캐릭터는 이월한다(6절).**
2. 메타 진행의 구체(어떤 직업이 어떤 조건으로 해금되는가, 해금이 시작 선택지만 넓히는가): 미정.
3. 난이도 선택을 둘 것인가, 하나의 하드 난이도만 둘 것인가: 미정.

## 6. 창고(보관) 설계 제안 (사용자 2026-10-28)
사용자 선택: **런 사이에 일부 캐릭터를 창고에 보관해 이월한다.** 이는 "런 사이에 전력은 이월하지 않는다"(DEC65)의 **예외**다.
- **효과:** 높은 티어를 한 판에 못 만들어도 여러 판에 걸쳐 키울 수 있어 "시간을 많이 쏟아야 만들 수 있다"(job-tree-plan.md 10절)가 판을 넘어 성립한다. 7성이 현실적으로 도달 가능해진다.
- **하드함을 지키는 장치(제안, 조합 가능):**
  1. **한도:** 창고 슬롯은 소수다(예: 3칸). 확장은 해금으로.
  2. **맡기는 시점:** 런 도중 **야영지에서만 맡길 수 있다**. 전투에서 쓰러진 유닛은 맡길 수 없다. 즉 죽기 전에 선택해야 하고, 맡긴 유닛은 그 런에서 전투에 나갈 수 없다(보호와 활용 사이의 선택).
  3. **꺼내기:** 다음 런 시작 때 정해진 수만 꺼낸다. 꺼낼 때 ★ 하락(예: −1)이나 비용을 둘 수 있다.
  4. **티어 상한 또는 유지비:** 높은 티어일수록 맡기는 대가가 크다.
- **한 판 안의 보관(대기석)과는 별개:** 한 판 안에서 합성 재료를 모으는 대기석은 M3 실측으로 정한다(설계서 정원).
- **위험:** "정말 사라진다"는 정서가 약해진다. 매 런 같은 캐릭터로 시작해 직업 다양성(100개 이상)이 덜 소비될 수 있다. 슬롯 수와 꺼낼 때의 손해로 완화한다.
- **열린 질문:** 슬롯 수, 맡기는 조건, 꺼낼 때 손해(★ 하락 여부), 승리한 런의 보관 규칙, 실패한 런에서도 맡긴 유닛은 남는가(맡긴 뒤 죽는 일은 없으므로 남는 것이 자연스러움).
