# 하드 로그라이크 난이도 설계안 (RUNE-88, 2026-10-29)

계획 문서 [difficulty-plan.md](difficulty-plan.md) 에서 "사용자 답 필요"로 남긴 항목을 설계안으로 바꾼다. 사용자가 선택을 에이전트에게 위임했으므로(2026-10-29),
공개 자료로 대표적 로그라이크 관행을 조사해 권고안을 하나씩 골랐다. 코드가 아니다.

상태 표기:
- **확정** = 사용자가 정했다(결정 장부 번호를 붙인다).
- **결정(에이전트 위임, 사용자 추인 대기)** = 사용자가 위임해 에이전트가 고른 값. 사용자가 추인하기 전까지 확정이 아니며, 뒤집혀도 다른 확정 사항이 깨지지 않게 적었다.
- **가설** = 수치. 시뮬레이션(RUNE-24)·시험 플레이로 바꾼다. 기준값(회복량·금화 등)은 M3 에서 정하므로 여기 숫자는 예다.

참고 게임은 구조만 우리 말로 요약했고 문구를 옮기지 않았다. 출처는 10절.

## 1. 설계 원칙 (이 문서 전체에 적용)
1. **어렵되 억울하지 않게.** 어려움은 선택과 정보에서 오고, 숨은 운에서 오지 않는다.
2. **화면의 숫자는 거짓말하지 않는다.** 표시 확률은 정확하고(설계서 M1 전 결정), 숨은 보정(연속 빗나감 뒤 몰래 명중률을 올리는 식)은 쓰지 않는다. 보정이 필요하면 공개 규칙으로 둔다.
3. **메타 진행은 폭을 넓히지 전력을 올리지 않는다.** 런 밖에서 쌓이는 것은 선택지·지식이다. 예외는 DEC69 의 창고 하나뿐이다.
4. **결정론.** 같은 시드와 같은 선택이면 같은 판이 나온다(SeededRng). 저장·재시작·시드 공유는 이 원칙 위에 선다.

## 2. "정말 사라진다"의 범위 (DEC65 를 항목별로 풀기)
| 런이 끝날 때 | 처리 | 근거 |
|---|---|---|
| 런 중 쓰러진 유닛 | 영구 소멸. 사본·환급 없음 | DEC28·DEC65 확정 |
| 살아남은 유닛(대기석 포함) | 소멸. 예외: 승리 런의 귀환 맡기기 1명(12-6) | DEC65 확정 + 예외는 위임 결정 |
| 카드·덱, 유물, 금화, 특수 재료, 물약류 | 소멸 | DEC65 확정 |
| 창고에 맡긴 유닛 | 남는다(11절 이후) | DEC69 확정(방향) |
| 도감(만난 직업·적·유물), 발견한 조합식 | 남는다 | DEC65 확정 |
| 직업 해금, 난이도 단계 해금, 기록(통계·최고 단계) | 남는다 | DEC65 확정 + 단계는 위임 결정(4절) |
- 숫자 예: 3막에서 전멸한 판에 ★4 기사, 유물 6개, 금화 120 이 있었다면 다음 판에는 셋 다 없다. 그 판에서 처음 만난 직업 2개는 도감에 남는다.

## 3. 메타 진행의 범위 — 결정(에이전트 위임, 사용자 추인 대기)
**권고안: 콘텐츠 해금만(옆으로 넓히는 해금). 영구 능력치 강화는 없다. 티어는 해금 대상이 아니다.**

## 4. 난이도 선택 — 결정(에이전트 위임, 사용자 추인 대기)
**권고안: 기본 난이도 하나(단계 0, 이미 어려움) + 클리어로 여는 누적 단계 10개(가칭 "각인 단계").**

### 4-1. 규칙
| # | 규칙 | 숫자 예(가설) |
|---|---|---|
| L-1 | 단계 0 이 기본이며 이미 하드다: 영구 소멸(V1), 구제 장치 없음 | 첫 판은 단계 0 고정 |
| L-2 | 단계 0 을 승리하면 단계 1 이 열리고, 그 뒤 **열린 최고 단계에서 승리할 때마다 다음 단계가 열린다.** 열린 단계 안에서는 자유롭게 고른다 | 단계 4 까지 열렸으면 0~4 중 선택. 단계 4 승리 → 5 해금 |
| L-3 | 단계마다 불이익 1개를 더하고 **앞 단계의 불이익을 모두 포함**한다(누적) | 단계 3 = 불이익 1·2·3 |
| L-4 | 단계는 계정 공통이다(직업별 아님) | 직업 100개 이상에 직업별 단계를 두면 반복이 과하다 |
| L-5 | 모든 불이익은 화면에 보이는 규칙이다. 명중 확률을 몰래 바꾸는 불이익은 두지 않는다 | — |

| 2 | 야영지 휴식 회복 감소 | 최대 HP 의 30% → 20% |

## 5. 억울함 방지 장치 — 결정(에이전트 위임, 사용자 추인 대기)
| # | 장치 | 숫자 예(가설) |
|---|---|---|
| A-1 | 표시 확률 정확, 숨은 보정 없음(1원칙 2) | 65% 로 표시하면 실제도 65% |
| A-2 | 적 행동 예고(이미 설계) | 모든 적의 다음 행동·대상·피해를 표시 |
| A-3 | **치명 경고:** 턴 종료 전, 예고된 적 피해 합이 현재 HP 이상인 아군에 경고 표식 | HP 6 기사에게 고블린 3 + 궁수 4 예고 → 7 ≥ 6 이므로 경고 |
| A-4 | **첫 전투 완충:** 1막 처음 2개 전투 노드는 일반 전투이고 적 수 ≤ 아군 수 | 아군 4명 → 첫 두 전투의 적은 4 이하 |
| A-5 | **보상 풀 구성(공개 규칙):** 보유 직업이 있으면 유닛 보상 3택 중 1개는 그 판에서 보유한 직업과 같은 이름 | 기사 ★1 ×2 보유 → 다음 유닛 보상 3개 중 1개는 기사 ★1 |
| A-6 | **빠른 재시작:** 패배 화면에서 버튼 1번으로 새 판 | 패배 → 새 판 첫 전투까지 30초 이내(목표) |
| A-7 | **사망 기록:** 유닛이 쓰러질 때 공격자·표시 확률·결과를 기록하고 패배 요약에 보인다 | "궁수 B, 명중 70%, 명중, 피해 4 → HP 0" |
| A-8 | **단일 자동 저장 + 난수 상태 저장:** 되돌리기 저장은 없고, 다시 불러와도 같은 결과가 나온다 | 65% 공격이 빗나간 뒤 종료·재실행 → 같은 시점에서 다시 쏘면 같은 빗나감 |
| A-9 | **시드 공유·일일 도전:** 같은 조건 비교. 이때 풀은 시드가 정하고 창고는 쓸 수 없다(12-9) | 친구와 같은 시드 → 같은 6계보 풀, 둘 다 창고 없이 시작 |
- 기각: 숨은 동적 보정(4-3), 연속 불운 뒤 몰래 확률 조정. 대안 "공개된 불운 보정(예: 보상 2회 연속 합성 진척이 없으면 다음 보상 보장)"은 A-5 와 겹쳐 보류한다.

## 6. 합성 투자 보호 장치 — 결정(에이전트 위임, 사용자 추인 대기)
**권고안: 순수 영구 소멸(V1)을 유지하고, 보호는 "정보 + 플레이어 선택 + 드문 수단"으로 준다. 죽은 뒤 되돌려 주는 장치는 기본에 없다.**
| # | 장치 | 숫자 예(가설) |
|---|---|---|
| P-1 | **출전 선택:** 대기석의 유닛은 그 전투에 나가지 않으므로 잃지 않는다. 키운 유닛을 아낄지 쓸지는 플레이어가 고른다 | 출전 4명, ★4 마검사를 대기석에 두면 그 전투에서는 안전 |
| P-2 | **치명 경고(A-3)를 ★ 높은 유닛에 더 강하게:** ★4 이상은 경고를 확인해야 턴 종료 | ★5 유닛이 치명 범위면 턴 종료 버튼이 한 번 더 묻는다 |
| P-3 | **드문 보호 수단:** 「응급 처치」(종이 변형 V2)류 카드·보호 유물을 고급 등급 이상으로 풀에 둔다. 기본 덱에는 없다 | 한 판 기대 획득 1장 이하 |
| P-4 | **창고:** 판 사이 보호는 창고뿐이다(11절 이후) | 야영지에서 맡기면 그 유닛은 그 판에서 더 잃을 일이 없다 |
| P-5 | **하위 티어 가치(job-tree-plan.md 8-2):** 높은 티어를 잃어도 판이 끝나지 않게 하위 티어가 주력으로 버틴다 | 검증 지표 D-4 |

| 대안 | 판단 | 이유 |
|---|---|---|
| **V1 + 정보·선택·드문 수단** | **권고** | DEC28·DEC62 그대로. 위험을 알고 고른 손실은 억울함이 아니라 긴장이다 |
| V2 응급 처치 상시화 | 보류(G0 결과에 따름) | 종이 판정에서 "영구 손실이 포기로 이어지면" 시험하기로 이미 정함(paper-prototype.md) |
| V3 부상(다음 전투 복귀) | 기각(기본으로는) | "정말 사라진다"가 사라진다. Wildfrost 도 부상을 기본에서 빼고 선택형 난이도로 옮겼다 |
| 죽으면 재료 일부 환급 | 기각 | 런 중 전력 손실을 되돌리는 장치라 DEC65 정서와 충돌 |
| 전투 중 퇴각(전장 이탈) | 보류 | 규칙 엔진·격자 규칙이 늘어난다. M2 이후 재검토 |

## 8. 검증 지표 (사전 등록, 2026-10-29 고정)
시험 전에 고정한다. 바꾸려면 시험 전에 이 표에 변경 이력을 남기고, 결과를 본 뒤에는 바꾸지 않는다. 지금 상태는 모두 **NOT RUN** 이다.
| # | 지표 | 측정 | 합격 기준 | 불합격 시 조치 |
|---|---|---|---|---|
| D-1 | 억울함 | 종이 프로토타입(G0) 기록 | 판당 2회 이하(paper-prototype.md 기준 그대로) | 정보 장치(A-3·A-7) 보강 후 재시험 |
| D-2 | 영구 소멸 뒤 포기 | 유닛이 쓰러질 때마다 "긴장/좌절/포기하고 싶음" 기록 | "포기하고 싶음" ≤ 전체 사망의 1/3 | V2 상시화 시험(6절 대안) |
| D-3 | 재시작 마찰 | 시험 플레이에서 패배 → 새 판 첫 전투 시작 시간 | 중앙값 30초 이하 | 패배 화면·시작 흐름 단축 |
| D-4 | 하위 티어 가치 | 자동 대전(RUNE-24) 3막 전투 | ★1~★3 직업이 출전 슬롯의 40% 이상 | job-tree-plan.md 8-2 장치 강화 |
| D-5 | 해금이 전력을 올리지 않음 | 같은 시드 1,000판: 해금 6계보 계정 대 42계보 계정 | 승률 차이 5%p 이하 | 해금 콘텐츠의 위력 예산 재조정 |
| D-6 | 풀 고정 효과 | 같은 조건에서 해금 수 6·20·42 의 판당 ★3 도달률 | 도달률 차이 5%p 이하 | 풀 크기·A-5 조정 |

| D-8 | 기본 난이도 | 외부 시험자(G2 이후) 첫 10판 | 1막 보스 도달 시험자 50% 이상, 단계 0 승리 판 비율 5~40% | 5% 미만이면 기본 하향 또는 접근성 모드 재검토, 40% 초과면 상향 |

## 9. 남은 질문
1. 대기석이 남아 있는데 출전 유닛이 모두 쓰러지면 패배인가(패배 조건 "전멸"의 범위). P-1 의 성립에 필요하다. 미확인.
2. 해금 조건(M-2)의 구체 목록 36개, 한 판 풀 크기(M-3)의 값: RUNE-24 와 G3 뒤에 정한다.
3. 각인 단계의 이름은 가칭이다.
