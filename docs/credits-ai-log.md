# 크레딧·라이선스 화면 설계 및 AI 사용 대장

> 정본: Confluence RUNE 스페이스 (페이지 미등록, RUNE-57 완료 시 등록 예정), 마지막 동기화일 2026-10-30

---

## 1부: 크레딧·라이선스 화면 설계

### 개요

Steam 출시 시 필요한 크레딧과 라이선스 고지를 정의한다.  
구현 시점: **M5a** (텍스트 동결 전).

---

### 1-1. 크레딧 화면 구성

| 항목 | 내용 | 비고 |
|---|---|---|
| 개발자 | 솔로 개발자 본인 | |
| 엔진 | Godot 4 (MIT 라이선스) | https://godotengine.org |
| 단위 시험 | GUT 9.7.1 (MIT 라이선스, Tom "Butch" Wesley) | https://github.com/bitwes/Gut |
| Steam 연동 | GodotSteam (라이선스 확인 필요, M5b 이후 도입) | M5b 전 표기 유보 |
| 무료 에셋 | RUNE-20 대장 기준 | 도입 시점에 출처·라이선스 추가 |
| AI 보조 | 일부 컨텐츠 AI 보조 생성 (2부 대장 참조) | |

크레딧 화면은 메인 메뉴 또는 설정 메뉴에서 접근한다. 구체적인 UI 배치는 M5a 구현 시 확정한다.

---

### 1-2. 라이선스 고지

게임 내 설정 메뉴 또는 별도 "라이선스" 화면에 표시한다.

**표기 의무가 있는 라이선스 유형**

| 라이선스 | 표기 의무 | 예시 항목 |
|---|---|---|
| MIT | 저작권 고지문 포함 | Godot 4, GUT |
| CC0 | 표기 의무 없음(권장) | CC0 에셋 |
| CC-BY | 저작자 표기 필수 | CC-BY 에셋 (RUNE-20 대장 기준) |
| OFL (Open Font License) | 폰트명·저작자 표기 필수 | 도입 폰트 확정 시 추가 |

표기 문구는 라이선스 원문에서 가져온다. 임의로 줄이거나 수정하지 않는다.

---

### 1-3. AI 사용 공개

**Steam 콘텐츠 설문 (AI Generated Content)**

- 도트 아트, BGM/SFX, 게임 내 텍스트·번역 중 AI 생성 도구를 사용한 경우 Steam 콘텐츠 설문에 "예"로 응답한다.
- 에셋이 확정되는 M5a 이전에 사용 여부를 최종 점검한다.

**크레딧 내 AI 사용 명시 문구 (예시)**

```
일부 컨텐츠는 생성형 AI 도구의 보조를 받아 제작되었습니다.
Some content was created with the assistance of generative AI tools.
```

- 실제 문구는 텍스트 동결(M5a) 시 확정한다.
- 어떤 에셋이 AI 보조인지는 2부 대장에서 관리한다.

## 2부: AI 사용 대장

AGENTS.md 규칙에 따라 AI 생성 콘텐츠를 기록한다.  
생성형 AI로 만든 에셋은 이 대장에 도구명·날짜·용도·프롬프트 요약을 기록한다.

| 항목 | 도구 | 용도 | 날짜 | 프롬프트 요약 | 비고 |
|---|---|---|---|---|---|
| 설계 문서 전반 | Claude Sonnet (OpenCode) | 문서 초안·EGM 검토·계획 수립 | 2026-10-20~ | 게임 설계·이슈별 요청 | 코드·에셋 아님 |
| AGENTS.md | Claude Sonnet (OpenCode) | 에이전트 규칙 초안 | 2026-10-20~ | 저장소 운영 규칙 작성 | 코드·에셋 아님 |
| (향후) 도트 아트 | 미정 | 콘셉트·시안 보조 | — | — | 참고 게임 이미지 입력 금지; 도입 시 기재 |
| (향후) BGM/SFX | 미정 | 생성 보조 또는 CC0 사용 | — | — | 라이선스 확인 필요; 도입 시 기재 |
| (향후) 게임 내 텍스트·번역 | 미정 | 텍스트 보조 | — | — | Steam 공개 대상; 도입 시 기재 |

**규칙**

- 생성형 AI로 만든 에셋은 이 대장에 행을 추가한다.
- 도구명·날짜·용도·프롬프트 요약을 반드시 기재한다.
- 설계 문서(코드·에셋 아님)는 도구명과 날짜 범위만 기재해도 된다.
- 참고 게임의 코드·에셋·이미지를 AI 도구에 입력하지 않는다(AGENTS.md 규칙).

**저작권 귀속**

솔로 개발자 본인. 국가별 AI 저작권 법령 변화를 모니터링하며, 출시 시점에 법적 현황을 재확인한다.
