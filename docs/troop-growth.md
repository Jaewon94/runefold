# 출전 인원 증가 방식 설계 (RUNE-77)

이 문서는 출전 인원이 4명에서 8명으로 늘어나는 방식을 다룬다. 상한 8은 잠정(종이 프로토타입 변형 N 확인 후 확정)이며, 늘어나는 구체적 트리거와 타이밍은 **미정**이다. 관련 결정은 design.md 「M1 전 결정」(정원 항목), roadmap.md 결정 16(2026-10-22)에 있다. 상위 이슈는 RUNE-4(M3 지도·보상·상점·유물).

상태 표기: **확정** / **잠정** / **미정** / **가정** / **해석** — design.md 기준.

---

## 1. 원칙

- **4명에서 시작해 최대 8명까지 늘어난다.** 방향 확정, 상한 8은 잠정(종이 프로토타입 변형 N 시험 후 확정).
- **한 판 안에서 자연스럽게 늘어나야 한다.** 인원이 증가하는 순간 플레이어가 "새 동료가 합류한다"는 느낌을 받아야 한다. 게임 메뉴나 외부 화면이 아니라 **노드 보상**으로 전달한다.
- 합류한 유닛은 기존 소대와 동일한 덱·에너지 체계를 공유하며 즉시 전투에 투입할 수 있다.
- 새 유닛의 직업은 랜덤 풀에서 결정되거나 선택 보상으로 제공된다(방식 미정, 「미결」 참조).

---

## 2. 증가 방식 (채택안)

### 2-1. 채택: 특정 노드 보상으로 +1

| 항목 | 내용 | 상태 |
|---|---|---|
| 트리거 | 새 세계 구역 첫 진입(막 분기점) 또는 희귀 이벤트 노드 | 미정 — 정확한 노드 종류와 위치 |
| 증가 속도 가정 | 막 1 시작: 4명 → 막 1 말: 5명(+1), 막 2 말: 6명(+1), 막 3 중: 8명(+2) | 가정 (M3 실측 전) |
| 구현 진입점 | M3 지도·보상 설계(RUNE-4) 와 함께. 보상 풀에 「유닛 합류」 항목을 추가한다 | 미정 |

막별 가정치 요약:

| 막 | 시작 인원 | 말 인원 | 증감 |
|---|---|---|---|
| 막 1 | 4명 | 5명 | +1 |
| 막 2 | 5명 | 6명 | +1 |
| 막 3 | 6명 | 8명 | +2 |

막 3의 +2는 보스 직전 한 번에 처리하거나 두 번에 나눠 줄 수 있다. 어느 쪽이든 합성 결정 타이밍과 맞물리므로 실측 전까지 가정으로 유지한다.

### 2-2. 대안 비교

| 방식 | 설명 | 기각·보류 사유 |
|---|---|---|
| 고정 지급 | 막 시작 시 자동으로 +1 | 느낌 없이 숫자만 늘어남. 「새 동료 합류」 연출 불가. 보류 |
| 선택 보상 | 노드에서 유닛 3종 중 1명을 선택 | 풀 구성이 필요하고 M3 이전에 확정 어려움. 채택안과 병행 가능(선택지를 보상 풀에 넣는 형태). 미정 |
| 조건부(보스 클리어) | 막 보스를 쓰러뜨리면 새 유닛 지급 | 템포가 보스에 몰림. 탐색 동기 감소. 보류 |
| 상점 구매 | 상점에서 유닛 슬롯 구매 | 경제 설계 부담이 큼. 대기석이 채워져 있지 않으면 효용 없음. 보류 |

현재 채택안은 "특정 노드 보상"이며, 선택 보상 형태를 포함할 수 있다. 고정 지급과 조건부는 느낌 또는 설계 복잡도 문제로 보류한다.

## 3. 합성과의 관계

새 유닛이 합류하면 기존 합성 집중 전략에 다음 영향이 생긴다.

- **합성 재료 풀 희석:** 출전 4명일 때는 같은 직업이 겹칠 확률이 높지만, 8명이 되면 직업 종류가 늘어 「같은 것 3개」 합성이 더 어려워진다.
- **대기석 압박 증가:** 새 유닛이 합류하면 대기석에 새 직업이 들어온다. 기존 합성 재료 자리를 차지할 수 있다(대기석 6칸, 잠정).
- **완화 방향:** 새 유닛 합류 타이밍을 야영지·정리 화면 직전에 두면 플레이어가 합성 결정을 한 뒤에 유닛을 받을 수 있다. 구현 시점에 고려한다.
- **직업 태그·덱 영향:** 새 유닛의 직업 카드가 덱에 추가될 경우(단 성장 규칙 적용 시) 손패·에너지 밸런스가 달라진다. 단 성장 설계(RUNE-72)와 맞춰서 정한다.

## 4. 대기석

| 항목 | 값 | 상태 |
|---|---|---|
| 출전 슬롯 상한 | 8명 | 잠정(변형 N 확인 후 확정) |
| 대기석 슬롯 | 6칸 | 잠정(M3 실측으로 조정) |
| 최대 보유 | 14명(출전 8 + 대기석 6) | 잠정 |

대기석은 합성 재료를 모으는 공간이다. 창고(런 사이 이월)와는 별개이며 한 판 안에서만 유지된다(design.md 「용어 정의」).

출전 인원이 늘어날수록 대기석 압박이 줄 수 있다(대기석 유닛을 출전으로 내보내면 빈 자리가 생김). 반대로 합성 재료를 대기석에 쌓는 전략이 어려워질 수 있다. 최적 슬롯 수는 M3 실측으로 정한다.

## 5. 종이 프로토타입 검증 (RUNE-76 변형 N)

변형 N(출전 6명·8명)은 상한 8을 확정하기 위한 시험이다(design.md 「용어 정의」 변형 N, paper-prototype.md L100~L105).

| 시험 항목 | 확인 내용 |
|---|---|
| 격자 혼잡 | 8×8 격자에 8명이 나올 때 이동 경로가 막혀 전술 결정이 줄어드는가 |
| 턴 길이 | 출전 인원이 늘수록 한 턴에 결정해야 할 양이 얼마나 늘어나는가 |
| 에너지 병목 | 공유 에너지 3으로 8명 중 누구에게 카드를 쓸지 선택 압력이 과해지는가 |
| 「새 유닛 합류」 체감 | 판 중간에 인원이 늘어나는 순간의 느낌이 자연스러운가 |
| 합성 빈도 | 인원이 많을수록 직업 풀이 희석되어 합성 빈도가 줄어드는 정도 |

변형 N 시험 결과에 따라 상한을 8이 아닌 수로 조정하거나, 막별 증가 속도 가정을 수정할 수 있다.

## 6. 미결

| 항목 | 내용 |
|---|---|
| 정확한 +1 트리거 이벤트 | 어느 노드 종류(이벤트·보스·엘리트·특수)에서 유닛 합류 보상이 나오는가 |
| 막 내 위치 | 막 시작·중간·말 중 어느 시점에 합류 보상이 오는가 |
| 대기석 크기 | 최대 보유 14명이 실제 합성 결정을 쾌적하게 만드는가(M3 실측) |
| 새 유닛 직업 결정 방식 | 랜덤 지급인가, 3종 선택인가, 세계(Realm) 제한이 있는가 |
| 합류 직업 카드 처리 | 새 유닛 합류 시 직업 카드가 덱에 즉시 추가되는가, 야영지에서 추가되는가 |
| 보유 한도 초과 시 | 출전 8 + 대기석 6 이 모두 찰 때 추가 합류 보상은 어떻게 처리하는가(선택 교체·거절 등) |
