# Runefold 1페이지 설계서

## 1. 게임 한 줄

판타지 로그라이크 | 타일 격자 전술 전투 + 카드 행동 + 합성 승급 | Steam 네이티브 PC (웹 방향 검토 중)

## 2. 핵심 3가지

| 축 | 내용 |
|---|---|
| **전술 전투** | 8×8 고정 타일 격자, 팀 턴, 확률 명중, 쓰러진 유닛 영구 소멸 |
| **카드 + 덱** | 소대 공유 덱, 손패 5장, 에너지 3 공유, 이동은 무료·행동만 카드로 제한 |
| **합성 · 티어** | 같은 것 3개 → 1개 승급(★1~★7), 서로 다른 재료 2~3개 → 조합식 새 직업, 직업 100개 이상 목표 |

## 3. 한 판 흐름 (목표 30~45분)

```
노드 지도 → 전투 → 보상(유닛·카드·유물) → 정리 화면(합성 확정)
→ 반복 → 엘리트 / 상점 / 이벤트 / 야영지 → 보스
```

- 출전 4명에서 시작, 판이 진행될수록 최대 8명까지 증가 (상한 잠정)
- 막당 노드 수는 M3 실측으로 확정

## 4. 하드코어 차별점

| 요소 | 내용 |
|---|---|
| **영구 소멸** | 전투 중 쓰러진 유닛은 그 런에서 사라진다 |
| **랜덤 획득** | 유닛·카드·유물 모두 확률 획득, 런 간 전력 이월 없음 |
| **티어 7성** | ★1~★7 승급, 높은 티어는 시간·운이 많이 필요 |
| **창고** | 런 사이 일부 유닛 이월 가능 (슬롯 수·조건은 미정) |

## 5. 확정 숫자

| 항목 | 값 | 상태 |
|---|---|---|
| 격자 | 8×8, 고저차 없음 | 확정 |
| 출전 인원 | 4명 시작 → 최대 8명 | 방향 확정, 상한 잠정 |
| 손패 | 5장 | 미정 (종이 프로토타입 시작값) |
| 에너지 | 3 (소대 공유) | 미정 (종이 프로토타입 시작값) |
| 직업 수 | 100개 이상 목표 | 방향 확정 |
| 티어 | ★1~★7 | 확정 |
| 검증 세트 | 기본 6종 + 합성 6종 | 확정 |

## 6. 검증 로드맵

```
G0 (종이)  →  M0 (뼈대)  →  G1 (전투)  →  G2 (지인)  →  M5 (수직 슬라이스)  →  출시
```

| 관문 | 내용 |
|---|---|
| G0 | 종이 프로토타입 3판 — 전투·합성·합성 빈도 검증 |
| M0 | 엔진 확정, 프로젝트 뼈대, 헤드리스 시험, Windows exe |
| G1 | 코드 전투 재미 확인 |
| G2 | 지인 플레이테스트 |
| M5 | 직업 100종·유물 30종·보스·저장 — 수직 슬라이스 |
| 출시 | Steam M6 심사 통과 |
